# DevVault

> **Your personal vault for developer resources.**

DevVault is a lightweight, privacy-friendly web application for saving, organizing, and managing useful developer resources in one place.

Whether it's documentation, GitHub repositories, AI tools, CSS resources, DevOps utilities, or anything else you want to keep handy, DevVault helps you keep everything organized and easy to find.

## ✨ Features

- 📚 **Resource Management** — Add, edit, and delete developer resources.
- 🔎 **Instant Search** — Quickly find resources by title, description, category, or tags.
- ⭐ **Favorites** — Keep your most important resources one click away.
- 🗂️ **Categories** — Organize resources by technology or purpose.
- 🏷️ **Tags** — Add custom tags for better organization.
- 💾 **Local Storage** — Your resources persist locally between sessions.
- 📤 **Export & Import** — Backup your resources as JSON and restore them whenever needed.
- 🔔 **Toast Notifications** — Clear feedback for important actions.
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile devices.
- ⚡ **Lightweight** — No frameworks, backend, or API keys required.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vaiibhavsengar/devvault.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd devvault
```

Then open `index.html` in your browser.

For the best development experience, use a local development server such as VS Code's **Live Server** extension.

## 💡 How It Works

DevVault stores your resources directly in your browser using **LocalStorage**.

No account is required and no external database is used.

Your workflow is simple:

```text
Add Resource
     ↓
Organize
     ↓
Search / Filter
     ↓
Favorite
     ↓
Open Resource
```

You can also export your resources to a JSON file for backup and import them later.

## 🔐 Privacy

DevVault is designed to be local-first.

Your saved resources are stored in your browser's LocalStorage and are not sent to a backend server.

> Clearing your browser's site data may remove locally stored resources, so use the export feature to keep a backup.
